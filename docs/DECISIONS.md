# Decisions

## 2026-09-02

- Keep HTML/CSS/JS vanilla and static hosting for speed, portability, and low maintenance.
- Use English for the first public iteration.
- Optimize for executive positioning rather than generic freelance conversion.
- Treat the local CV as the primary source and LinkedIn as a public cross-check.
- Avoid subjective skill percentage bars and unsupported metrics.
- Prefer licensed or owner-supplied images; do not download arbitrary Google images.
- Keep automated smoke tests and manual visual review separate.
- Require `README.md`, `CHANGELOG.md`, and `ADDENDUM.md` updates for every meaningful batch.
- Use a visible Playwright browser with a local ignored profile for manual LinkedIn login; never automate authentication challenges or store session data in the repository.
