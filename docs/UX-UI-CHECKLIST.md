# UI/UX Checklist

## Automated Smoke Coverage

- [ ] Page loads with HTTP 200.
- [ ] Title and meta description exist.
- [ ] No console errors or failed requests.
- [ ] Internal anchors resolve to visible sections.
- [ ] CV download and external links are reachable.
- [ ] Mobile navigation opens and closes.
- [x] Single dark theme is applied consistently across the document.
- [ ] Keyboard focus remains visible and usable.
- [ ] Reduced-motion preference is respected.
- [ ] Images have useful alt text and stable dimensions.
- [ ] No horizontal overflow.

## Manual Review

- [ ] Hero communicates role and value within the first viewport.
- [ ] Information hierarchy is scannable at 390px, 768px, and 1440px.
- [ ] Copy is concise, professional, and supported by a source.
- [ ] Text never collides with controls or media.
- [ ] Contrast is readable across the dark theme surfaces and accents.
- [ ] Tap targets are comfortable on touch screens.
- [ ] Focus order follows the visual and semantic order.
- [ ] Motion remains calm and does not obscure content.
- [ ] The page feels like an executive profile, not a generic template.
